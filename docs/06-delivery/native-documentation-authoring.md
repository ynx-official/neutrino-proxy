# 文档站官方格式整理与验证

状态：Review

## 已确认范围

2026-10-30 用户要求将现有文章结构和配置尽量整理为 VitePress 官方形式，减少自定义逻辑，同时保留原来的链接、标题锚点并实际验证。本次沿用 VitePress 1.6.4、既有 Mintlify 样式、源文件目录和课程正文，不升级框架或发布站点。

## 整理结果

- 首页直接使用官方 `layout: home`、`hero`、`features`，删除 `transformPageData` 中的旧首页字段转换。
- 旧文章显式写入总标题；原来将正文小节写为一级标题的文章，改为文章总标题加下级标题。小节文字和旧书签保留。历史主题提示直接使用源文件中的官方 `info` 容器。
- `/blog/` 的文章列表成为普通 Markdown 链接，不再在渲染时插入。新增文章时按维护说明更新索引。
- 普通截图改为 Markdown 图片；首页保留的复杂 HTML 通过本页导入官方 `withBase` 处理资源。HTML 与样式块的分隔空行直接写入源文件。删除全局 `$withBase` 和 HTML URL 渲染重写。
- 导航和分组在 `.vitepress/navigation.mjs` 中直接使用官方配置，保留全部栏目、链接、顺序与展开行为。删除按目录自动拼装导航的脚本；课程侧栏使用官方 `/learn/` 前缀配置。
- 普通新文章可以省略 `permalink`，使用原生文件路由与一级标题。已有 `permalink` 仍映射为原来的目录首页；没有重写需求的文件不生成 `rewrites` 条目。
- 删除未再直接使用的 `markdown-it-container` 依赖声明；VitePress 自带提示容器继续可用。旧批量 frontmatter 工具不参与写作、构建或 CI。

## 保留的兼容边界

- 原有 `/pages/<id>/`、`/learn/<slug>/`、`/blog/` 通过官方 `rewrites` 保留，含无尾斜杠入口。不移动源文件到不透明 ID 目录，保留按主题查找文章的便利。
- `markdown.anchor.slugify` 保留既有 VuePress 标题 ID 的规则，包括中文标点和数字前缀，避免批量更换标题书签。后续如进一步移除此函数，须先为既有标题提供显式锚点并验证所有书签。
- 中文搜索分词、图片缩放、部署清单和链接验证服务于现有功能，不参与正文内容改写，继续保留。

- 根路径 `/`：25 项单元测试、生产构建、99 页与 7,890 条本地链接/资源检查通过；109 项 Chromium 浏览器测试全部首次通过。
